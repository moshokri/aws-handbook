# AWS Handbook

A brief handbook of AWS services. It follows the structure of the GCP handbook.

## Writing rules

All documents use ASD-STE100 (Simplified Technical English):

- One topic in each sentence.
- Maximum 20 words in a procedural sentence. Maximum 25 words in a descriptive sentence.
- Use the active voice.
- Use simple words with one meaning.
- Use lists and tables for steps and comparisons.
- Use Mermaid diagrams. Do not use images, except the official AWS service icons in `icons/`.
